# AI Chat

一个纯前端的多模型 AI 对话应用，零后端，直接部署到 GitHub Pages 即可用。

## 功能

### 对话
- **普通模式**：一问一答，流式输出
- **Waifu 模式**：像真人聊天——可以连着发好几条，AI 等你说完再回；回复拆成多条气泡逐条弹出；你中途插话会打断她，没说完的内容会带进下一轮
- 多轮上下文、长对话自动压缩（滚动摘要）、摘要置顶可折叠

### 多供应商
- **聊天**：默认公益接口，可添加任意多个 OpenAI 兼容接口（名称 / Base URL / Key / 模型），点击切换
- **生图**：默认 Gitee AI（`z-image-turbo`，1024×1024，base64 返回），同样支持多套并存
- 上下文上限跟着接口走：免费接口固定 80000 字符（受请求体 256 KB 限制），自定义接口可单独配置，提醒阈值用百分比

### 生图
- 由聊天模型通过 `<genimg prompt="..." />` 文本协议触发，模型自己把需求翻成英文 prompt
- 支持配置「AI 自画像描述」，自拍场景会带上固定外貌
- 图片存 IndexedDB，设置页可逐张删除或一键清空

### 提示词
- 全局系统提示词；可在对话列表的齿轮里给单个对话设置专属提示词（覆盖全局）
- 每轮自动注入当前时间，并明确告诉模型以它为判断「今天 / 昨天 / 多久没聊」的唯一基准
- 压缩时按「轮」保留最近 N 轮原文，其余整理成结构化的记忆档案（含时间坐标）

### 其他
- 全量导入导出（对话 + 设置 + 提示词 + 背景 + 图片）
- 深浅色主题、四种气泡样式、自定义背景与头像、消息时间戳、消息搜索、右键菜单
- 对话存 IndexedDB，不受 localStorage 5MB 限制

## 项目结构

```text
ai-chat/
├── index.html
├── css/style.css
└── js/app.js
```

原生 HTML / CSS / JavaScript，无构建步骤。

## 使用

直接用浏览器打开 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8080
```

首次使用生图功能，需要在「设置 → 生图服务」里给默认接口填一次 API Key（只存在本机浏览器）。
