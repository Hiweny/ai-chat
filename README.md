# AI Chat - 智能对话

一个简洁优雅的 AI 聊天应用，基于免费 API 构建，支持多轮对话、流式响应、对话管理、主题切换等丰富功能。

## 功能特性

- **多轮对话** — 支持连续对话，保留上下文记忆
- **流式响应** — 实时显示 AI 回复，打字效果
- **对话管理** — 侧边栏管理多个对话，新建/切换/删除
- **手动总结** — 一键总结对话历史，压缩上下文继续对话
- **广告过滤** — 自动过滤 API 返回中的广告信息
- **Markdown 渲染** — 完整支持 Markdown 语法，包括代码高亮
- **主题切换** — 浅色/深色/跟随系统三种主题
- **气泡样式** — 现代简约/毛玻璃/水玻璃/无气泡四种风格
- **自定义头像** — 支持设置用户和 AI 的自定义头像
- **自定义背景** — 支持背景图片上传、模糊度和透明度调节
- **消息时间戳** — 可选显示每条消息的时间
- **消息复制** — 悬浮显示复制按钮，一键复制
- **对话导出** — 将对话导出为文本文件
- **全屏模式** — 沉浸式对话体验
- **响应式设计** — 完美适配桌面和移动端
- **数据持久化** — 所有设置和对话自动保存到本地

## 快速部署

本项目为纯静态网站，无需后端服务。部署方式：

1. 克隆仓库
2. 用任意静态托管服务部署（GitHub Pages、Vercel、Netlify 等）

### GitHub Pages 部署

1. 进入仓库 Settings > Pages
2. Source 选择 main 分支
3. 保存即可

## 技术栈

- HTML5 / CSS3 / JavaScript (Vanilla)
- Showdown.js — Markdown 解析
- Highlight.js — 代码语法高亮
